## 🎯 WHAT IS CAREERFORGE?

CareerForge is an **AI-powered career agent** that tailors your resume, cover letter, and career strategy for any job you want.

**In 5 minutes:**
1. Upload your resume (PDF)
2. Paste a job description
3. Answer optional questions about yourself
4. Select what you want (resume, cover letter, interview tips, salary negotiation)
5. Get AI-optimized career documents

## 🚀 HOW TO USE (STEP BY STEP)

### **For First-Time Users:**

1. **Go to:** `https://careerforge.vercel.app` (or your local: localhost:3000)

2. **Step 1 - Upload Resume:**
   - Click "Choose File"
   - Select your resume PDF (< 5MB)
   - See preview of extracted text
   - Click Next

3. **Step 2 - Job Description:**
   - Copy-paste the entire job description
   - Or type a description
   - See character count
   - Click Next

4. **Step 3 - Smart Questions (Optional):**
   - Answer any/all questions:
     - Target role: e.g., "Senior Software Engineer"
     - Industries: e.g., "Tech, AI, Startups"
     - Achievements: e.g., "Led team of 5, shipped product, 100k users"
     - Skills to emphasize: e.g., "React, Python, Leadership"
     - Work style: e.g., "Collaborative"
   - Or skip all if in a hurry
   - Click Next

5. **Step 4 - Select What You Want:**
   - Check boxes for what to generate
   - Recommend: Check "Optimized Resume" + "Missing Skills"
   - Can select all or just one
   - Click Next

6. **Step 5 - Configure AI Provider:**
   - Click "Your Forge" (settings)
   - Pick provider: Anthropic / OpenAI / Gemini / etc
   - Enter your API key (get free from provider)
   - Select model (auto-fetches available models)
   - Click "Apply Settings"

7. **Generate Results:**
   - Click "Generate" (big blue button)
   - Wait 10-30 seconds
   - See match score + all requested outputs
   - Copy any content to clipboard

## 💡 TIPS FOR BEST RESULTS

### **Resume Tips:**
- Include all your experiences, not just highlights
- Agent will select what's most relevant
- Use standard resume format (bullets, sections)

### **Job Description Tips:**
- Copy the entire job posting
- Include company culture/values if available
- Longer descriptions = better matching

### **Smart Questions:**
- Be honest about what excites you
- Agent uses this to personalize recommendations
- "I don't know" is fine—just skip

### **Skill Selection:**
- Only select skills you truly have
- Agent will know if you're bluffing
- It's honest feedback if you're missing something

### **Generated Content:**
- Agent output is a STARTING POINT, not final
- Always review and personalize
- Use agent output as a template
- Add your own voice and specific examples

## ❓ FAQ

**Q: Is my data private?**  
A: Yes. Resumes are processed immediately and never stored. Smart questions stay in your browser. Your API keys are yours.

**Q: Do I need a paid API key?**  
A: No. All major providers (Anthropic, OpenAI, Google) offer free credits ($5+). That's enough for 100+ optimizations.

**Q: Can I use multiple API keys?**  
A: Yes. Add multiple keys per provider in settings. Switch anytime.

**Q: How long does optimization take?**  
A: Usually 10-30 seconds depending on provider and resume length.

**Q: Can I edit the generated content?**  
A: Yes. Copy to clipboard and edit in any text editor.

**Q: Does it work on mobile?**  
A: Yes. Full responsive design. Not optimized for PDF upload on mobile yet (Phase 2).

## 🐛 TROUBLESHOOTING

| Issue | Fix |
|-------|-----|
| "Invalid API Key" | Check key is correct in settings |
| "No models found" | Verify API key is valid & has permissions |
| "PDF extraction failed" | Make sure file is a real PDF, not an image |
| "Request timeout" | Try a shorter job description, or switch provider |
| "Slow performance" | Clear browser cache, close other tabs |
